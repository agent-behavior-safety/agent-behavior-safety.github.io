Evaluation

Assessing intrinsic and external security risks

The evaluation section distinguishes intrinsic failures under benign conditions from externally induced security risks.

I

Intrinsic Security Risks

Long-horizon agent failures can emerge without adversarial interference, including reasoning flaws, state-maintenance errors, and execution-strategy deviations.

E

External Security Risks

Evaluation also covers risks introduced through adversarial inputs, external skills, tool ecosystems, and other interaction surfaces.
